회원 ID는 중복 체크를 실시하여 중복되는 경우, "이미 등록된 회원 ID 입니다." 알람을 표시하고 다시 회원 ID를 입력 받도록 한다.
비밀번호는 8자리 이상 영어 대문자, 소문자, 숫자와 특수문자를 이용하여 생성하도록 표시하고 위의 규칙이 지켜지지 않으면 다시 비밀번호를 입력하도록 한다.
비밀번호(확인)은 비밀번호와 일치하도록 한다.
휴대폰 번호는 정규식을 이용하여 010-0000-0000 양식으로 입력 받고, 그 외의 양식으로 입력하면 "올바르지 않은 양식입니다." 알람을 표시하고 다시 입력하도록 한다. 
사업장 이메일은 정규식을 이용하여 mail@domain.com양식으로 입력 받고, 그 외의 양식으로 입력하면 "올바르지 않은 양식입니다." 알람을 표시하고 다시 입력하도록 한다. 
사업장 전화번호는 정규식(/^0\d{1,2}-\d{3,4}-\d{4}$/)을 이용하여 입력되는 전화번호를 확인하여 입력 받도록 한다.
사업장 주소는 '다음' '도로명 주소 API'를 활용하여 주소를 입력 받도록 한다.

[ 초기화 ] 버튼을 누르면 현재 입력한 값들을 모두 리셋한다.

성공적으로 파일을 읽어들이면 "성공적으로 파일을 업로드하였습니다" 메시지를 팝업하여 보여주고, "소스" 액셀 파일의 1행부터 20행까지의 내용을 SheetJS등의 라이브러리를 활용하여 읽어와 테이블 형식으로 보여주고 테이블이 끝나는 행 하단에 [ 확인 ] 버튼과 [ 다시 업로드] 버튼을 생성한다. 

[ 확인 ] 버튼을 누르면 "소스" 액셀 파일 전체를 읽어들여 MySQL DB의 "source_data" 테이블에 저장하고, "변환 양식" 액셀 파일의 컬럼명을 읽어와 DB의 "result_data" 테이블의 컬럼으로 저장한다. 가장 경제적인 Gemimi API 모델을 이용하여 "source_data_table"의 각 컬럼명과 "result_data_table" 의 컬럼명을 비교하여 컬럼명이 가장 유사한 값으로 각 컬럼의 값들을 매핑하여 "mapped_data" 매핑 페이지로 이동하여 보여준다.

[ 다시 업로드 ] 버튼을 누르면 다시 파일 불러오기 화면으로 이동한다. 

파일 업로드에 실패하면 "파일 업로드에 실패하였습니다." 오류 메시지와 함께 다시 "소스" 액셀 파일과 "변환 양식" 액셀 파일을 불러오는 페이지로 이동한다.

매핑 페이지에서는 "source_data_table"의 컬럼명과 "result_data_table"의 컬럼명을 다음의 ASCII 아트의 양식을 참고하여 한 행씩 표시되도록 만든다.

[ 템플릿 저장 ] 버튼을 누르면 매핑 규칙 이름을 입력하는 창을 띄우고, 매핑 규칙의 이름을 입력 받는다. DB의 mapping_rules 테이블의 소스 파일의 컬럼명은 source_column에 이에 대응하는 변환 양식 파일의 컬럼명은 result_column 값에 저장하고, 로그인한 사용자의 ID를 user_id 컬럼에 저장하고, 매핑 규칙 이름은 mapping_name 컬럼에 저장한다.

mapping_rules 테이블 구조
id : INT, primary key
user_id : VARCHAR, Not null
mapping_name : VARCHAR, Not null
source_column : VARCHAR
result_column : VARCHAR
created_time : Time_stamp

[ 매핑 규칙 선택 ]은 mapping_rules 테이블의 user_id를 조건으로 mapping_name을 중복 없이 찾아 정렬하여 드랍 다운 방식으로 보여주고, 매핑 규칙을 선택하면 mapping_name에 해당하는 mapping 데이터의 source_column에 이에 대응하는 변환 양식 파일의 컬럼명은 result_column 값을 매핑 화면에 보여준다. 각각의 매핑 컬럼은 드랍 다운 박스로 구성되어 클릭하면 해당 테이블의 다른 컬럼값을 선택할 수 있다.

[ 저장하기 ] 버튼을 클릭하면 현재의 매핑 규칙으로 source_data_table의 각 컬럼의 값들을 "결과" 액셀 파일에 입력하고 ("발주서_" + 사용자 id_ + 날짜)이름의 액셀 파일로 생성한다.

액셀 파일 생성에 성공하면 "발주서 파일 생성에 성공하였습니다." 알림을 보여주고 이메일 전송 페이지로 이동한다.

"이메일 템플릿 선택" 항목은 기본적으로 "기본 거래처"로 설정하고 클릭하면 email_template 테이블의 user_id를 조건으로 mail_template_name을 중복 없이 찾아 정렬하여 드랍 다운 방식으로 보여주고, 템플릿을 선택하면 user_id와 mail_template_name에 해당하는 (mail_recipient, mail_text)컬럼의 정보를 읽어와서 받는 사람(mail_recipient), 본문 내용(mail_text) 란에 입력하여 화면에 표시한다. 

[ 첨부파일 미리보기 ] 버튼을 누르면 생성된 첨부파일("발주서_" + 사용자 id_ + 날짜)이름의 액셀 파일을 팝업하여 보여준다.

이메일 전송에 성공하면 "이메일 전송에 성공 했습니다." 알람 메시지를 띄워주고, 이메일 전송에 실패하면 "메일 전송에 실패하였습니다." 알람 메시지를 띄우고, source_data_table과 result_data_table의 내용을 모두 삭제하고 이메일 전송 페이지로 다시 이동한다.
